# 🧮 CalculatorSOS – Silent Emergency Alert System

🚨 A smart emergency alert system disguised as a calculator.

CalculatorSOS looks like a normal calculator app but can silently send emergency alerts with location and user details when triggered.

---

## 🔥 Features

- 🧮 Fully functional calculator
- 🚨 Hidden SOS trigger system
- 📍 Real-time location detection
- 📩 Telegram emergency alerts
- 📲 Twilio SMS alerts
- 👆 Triple tap trigger
- 📳 Shake detection trigger
- 🔊 Volume button triple press trigger
- 🔐 Secure local storage (No server database)

---

## 🚨 Emergency Trigger Methods

You can activate SOS using:

- Type `100=` in calculator
- Press SOS button
- Triple tap screen
- Press volume button 3 times
- Shake phone

---

## 📍 What Happens During Emergency?

- 5-second countdown starts
- Location is fetched
- User medical details are attached
- Alert is sent to:
  - Telegram
  - SMS contacts (via Twilio)

---

## 🛠 Technologies Used

- HTML5
- CSS3 (Responsive Design)
- JavaScript (Vanilla JS)
- Telegram Bot API
- Twilio SMS API
- Geolocation API

---

## 🔒 Privacy & Security

- All user data stored in localStorage
- No external database
- Location shared only during SOS
- No background tracking

---

## 📱 How To Use

1. Open the app
2. Setup your profile
3. Add emergency contacts
4. Configure Telegram / Twilio
5. Use calculator normally
6. Trigger SOS in emergency

---

## ⚙️ Setup Instructions

### 🔹 Telegram Setup
1. Create bot using @BotFather
2. Get Bot Token
3. Get Chat ID
4. Paste into settings panel

### 🔹 Twilio Setup
1. Create Twilio account
2. Get Account SID
3. Get Auth Token
4. Add Twilio phone number
5. Add emergency contacts
